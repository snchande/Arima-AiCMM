# Register Agent Card

## Purpose

Register a pre-existing Agent Card JSON file into the AiCMM catalog. This is for cards that have already been created (e.g., exported from another system, hand-crafted, or generated by another tool).

## Workflow

1. **Read the card** — Load the JSON file from the provided path
2. **Validate schema** — Ensure it has required fields (agent, capabilityProfile, schemaVersion)
3. **Validate governance** — Check all 7 governance rules pass
4. **Register** — Either:
   - Copy to `examples/` directory (file-based catalog)
   - POST to `http://localhost:8080/api/agent-cards` (API-based)
5. **Confirm** — Return the registration result with URL

## Prerequisites

- Agent Card must be valid JSON matching AiCMM schema v0.2.0
- Card must have `agent.name` and `capabilityProfile` at minimum
- All 7 governance rules should pass (warnings issued if not)

## Validation via API

```bash
# Validate before registering
curl -X POST http://localhost:8080/api/validate \
  -H "Content-Type: application/json" \
  -d @path/to/card.json
```

## Registration Methods

### Method 1: File Copy (offline)
Copy the card to `examples/<agent-name>-agent-card.json` in the AiCMM project.

### Method 2: API (when server is running)
```bash
curl -X POST http://localhost:8080/api/agent-cards \
  -H "Content-Type: application/json" \
  -d @path/to/card.json
```

### Method 3: CLI
```bash
java -jar aicmm-cli/target/aicmm-cli-0.1.0-SNAPSHOT.jar register --card path/to/card.json
```

## Required Card Structure

```json
{
  "schemaVersion": "0.2.0",
  "agent": { "name": "...", "category": "digital|embodied|hybrid", "description": "..." },
  "capabilityProfile": { /* 12 dimensions with position, score, confidence, evidence */ }
}
```

## After Registration

The card will appear in:
- Web catalog: http://localhost:8080/catalog
- API listing: GET http://localhost:8080/api/agent-cards
- File system: `examples/` directory
